Construction
  • 24pt grid, 2pt safe margin; every vessel sits on the same baseline (y 20) with the same 2pt stroke and 1pt corner radii, so the set reads as one hand.
  • One vessel per type, told apart by silhouette not detail: tall-with-handle, stemmed-deep, short-wide, stemmed-cone, tall-plain.
  • Liquid is one cut line (foam, fill level); nothing decorative — no bubbles, garnish, or straws, matching “a mark, not a message”.
  • Other carries an ellipsis, the platform’s own sign for “anything else”. The untyped drink stays a measure, not a vessel (the drop), as the code comment asks.
  • Alcohol-free is outline in both weights: an outline is the design system’s own signal for “off the ramp”.
  • Filled, like every other symbol the app uses; the 2pt stroke rule governs cut lines and the alcohol-free ring so the set reads as one family.

Handoff — one change site

Every surface reads DrinkType.symbolName (Today row, ＋ pill, History row, Trends composition row) or hard-codes the two companions (heart.text.square in both rows and Trends; checkmark.circle in Today, day sheet, bulk fill, Trends). Add the eight SVGs to Assets.xcassets as custom symbols and swap the names in those places; the code path does not change.

case .beer: "tally.beer" case .wine: "tally.wine" case .spirit: "tally.spirit" case .other: "tally.other" case .unspecified: "tally.standard" // companions "tally.health" // was heart.text.square "tally.alcoholfree"// was checkmark.circle

Custom symbols inherit the accent through foregroundStyle exactly as system ones do, so the 500/400 pairing and the secondary-label fallback on the untyped row keep their contrast math.

Files & decisions
  • icons/*.svg — 24×24 filled source art; drop into the Regular-M slot of an SF Symbols template and let iOS derive sizes and weights.
  • Cocktail is drawn and the Tweaks toggle places it in the picker, but adding it is a product decision — it needs a default size/ABV (DrinkType.swift), a Siri entity, and a localized name.
  • Other loses the cup-and-saucer: a hot drink reads as “not alcohol”, the opposite of what the row records.
  • Spirit becomes a shot glass, not a flask — the flask reads as laboratory; the shot is the 1.5 oz default the type is defined by (ADR-0005).
